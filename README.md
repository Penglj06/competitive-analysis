# competitive-analysis

![version](https://img.shields.io/badge/version-1.3.1-blue.svg)
![license](https://img.shields.io/badge/license-MIT-green.svg)
![type](https://img.shields.io/badge/type-agent--skill-orange.svg)

把「竞品分析」从**截图合集 + 功能对比表 + 一句套话结论**，升级为**可执行的产品决策输入**。

最终回答的不是「竞品怎么做」，而是 —— **「看完竞品之后，我们该怎么做」**。

---

## 为什么需要它

大多数竞品分析会滑向三种失败形态：

| 常见失败 | 表现 | 本 skill 的约束 |
|---|---|---|
| 资料整理 | 堆一堆截图和官网文案，没有判断 | 强制「借鉴/照抄二分」，每条必须落到决策 |
| 编指标 | 拿不到 DAU/留存就凭感觉编一个 | 硬性禁止编指标，只反推**可观察的取舍** |
| 套话结论 | "A 更完整、B 更简洁，我们可以结合参考" | 明令禁止这类结论，必须给改造方案或替代方案 |

它有一套**硬性约束**来保证不跑偏：定位不清先停下来问、竞品名单需你确认、每条结论标证据等级、决策必须分「立即做 / 先验证 / 不做」。

---

## 和同类 skill 的差异

社区里已有多个竞品分析类 skill，多数定位是**「生成对比矩阵 / SWOT / 功能对比表」**——产出一份报告即结束。

本 skill 的差异在于它是一套**决策方法论**：

| 维度 | 一般竞品分析 skill | 本 skill |
|---|---|---|
| 产出终点 | 一份对比报告 | 三类决策（含成功标准与复盘点） |
| 证据处理 | 不区分来源 | 四档分级 + 深度走查升级证据 |
| 对竞品的判断 | 描述它做了什么 | 反推它**做重了什么、牺牲了什么** |
| 借鉴结论 | "值得参考" | 二分：可借鉴（含改造方案）/ 不能照抄（含风险与替代） |
| 信息获取 | 依赖公开资料 | 优先用浏览器**实际走查**竞品页面 |

## 七步工作流

```
① 定目标 ── 解决什么问题 · 支撑什么决策 · 什么信息不该影响决策
② 选对象 ── 分三层（直接 / 间接 / 跨行业），每层定数量与深度
③ 拆流程 ── 不看表面形态，看用户从进入到完成目标的运转路径
④ 多维比 ── 不比「有没有」，比入口·场景·成本·闭环·代价·业务目标
⑤ 反推取舍 ── 做重了什么、简化了什么、牺牲了什么（不反推指标）
⑥ 借鉴/照抄 ── 可借鉴（+怎么改造） vs 不能照抄（+风险与替代）
⑦ 决策输出 ── 立即做 / 先验证（含成功标准）/ 不做
```

三条贯穿原则：**流程 > 页面**、**策略 > 功能**、**迁移 > 复述**。

## 证据分级（核心机制）

每条关于竞品的结论都必须标注来源，不允许把推测当事实：

| 等级 | 含义 |
|---|---|
| **一手** | 真实注册使用过、真实用户访谈、拿到真实数据 |
| **走查** | 用浏览器实时访问竞品页面看到的内容 |
| **公开** | 官网文案、帮助文档、媒体报道、财报 |
| **推断** | AI 推测 —— 必须附「用什么信号可佐证或证伪」 |

> 关键边界：**走查 ≠ 一手**。走查只能看到公开页面，看不到登录后的真实使用、真实数据和用户反馈——这部分如实标「未验证」，不硬凑。

## 快速开始

**安装**

```bash
# 方式一：SkillHub 社区安装（推荐）
skillhub install competitive-analysis --namespace user_cba53469

# 方式二：手动安装到 WorkBuddy
git clone https://github.com/Penglj06/competitive-analysis.git ~/.workbuddy/skills/competitive-analysis
```

**触发**（命中任一即启动）

```
帮我做一次竞品分析（对象：XXX）
分析下 XX 和我们的差异
这个功能要不要做，先看下别人怎么做的
我们的产品和 XX 比，差在哪 / 强在哪
```

**你会拿到什么**

一份含图表的 Word 报告（`competitive-analysis报告.docx`）+ Markdown 源 + 走查记录，核心结构包括：我方基线、竞品分层、流程拆解、证据等级标注的对比表、借鉴/照抄二分表、**决策三分类**。

完整产出形态见 [`examples/示例报告-结构示范.md`](examples/示例报告-结构示范.md)。

## 依赖说明

核心分析（定位 → 分层 → 拆解 → 对比 → 反推 → 二分 → 决策）**不依赖任何外部工具**，装了就能跑。

以下两项为可选增强：

| 能力 | 依赖 | 缺失时会怎样 |
|---|---|---|
| 深度走查（把证据从「公开」升级为「走查」） | `agent-browser`（需 `npm install` + 下载 Chromium） | 降级为公开资料搜索，证据标「公开」 |
| Word 报告输出 | `html-to-docx` skill | 降级交付 Markdown + 内嵌图表 HTML |

## 常见问题

**Q：竞品需要登录才能看，怎么办？**
A：如实标注「无法走查」，降级为公开资料，并在报告里说明证据边界。不硬凑结论。

**Q：能自动拿到竞品的 DAU、留存、转化吗？**
A：不能，也不应该编。本 skill 明确禁止虚构指标，只反推可观察的取舍（做重了什么、牺牲了什么）。

**Q：官网数字和媒体报道对不上？**
A：如实并列两个口径，标注「官方自述，未独立核验」，不替你判定谁对。
